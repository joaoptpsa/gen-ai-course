# Course 2 — Pre-reads

Optional reading and reference material, grouped by topic. You do not need to
read everything before class. See also the [Course 1 pre-reads](course-01-pre-reads.md).

## Agent architectures

- [Anthropic — Building Effective Agents](https://www.anthropic.com/engineering/building-effective-agents)
  - **When to read:** when comparing workflows, single agents, and multi-agent systems.
  - **Focus:** the distinction between workflows and agents, when to use agents, and composition patterns.
  - **Note:** this architecture article was published in 2024. Check current documentation for tooling examples; it is not the course setup guide.

## Model Context Protocol (MCP)

- [Model Context Protocol — Architecture overview](https://modelcontextprotocol.io/docs/learn/architecture)
  - **When to read:** when connecting an application to an MCP server.
  - **Focus:** host, client, and server responsibilities, capabilities, and transports.

## Tool approval

- [PydanticAI — Deferred Tools](https://pydantic.dev/docs/ai/tools-toolsets/deferred-tools/)
  - **When to read:** when working with actions that require human approval or a result provided later.
  - **Focus:** human-in-the-loop approval and pausing a conversation.

## Agent evaluation

- [Anthropic — Demystifying evals for AI agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
  - **When to read:** when defining test cases and success criteria.
  - **Focus:** evaluation structure and the distinction between the execution trace, the response, and the task outcome.
